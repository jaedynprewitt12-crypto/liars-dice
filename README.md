# Liar's Dice V2

Online-ready browser multiplayer Liar's Dice for 2–6 players.

## Local test

Open a terminal in this folder:

    npm.cmd install
    npm.cmd start

Then visit:

    http://localhost:3000

## Deploy

This project is ready for a Node-compatible host such as Render. Use:

Build command: npm install
Start command: npm start

The server uses PORT from the hosting provider and keeps each room in memory.
